# Current texture provenance status

The `shared-*` files in this directory replaced an earlier, separately named
set of CC0 surface scans. The repository does not currently record how each
replacement was produced, its original source, or a licence that permits
redistribution.

The deleted provenance record covered only these removed files:

- Poly Haven `Book Pattern` colour and height scans (CC0 1.0);
- ambientCG `Paper 001` colour scan (CC0 1.0).

That historical record does **not** transfer to the current files merely
because they serve similar runtime roles.

Do not publish or redistribute the current `shared-*` textures until each file
has either verifiable original-generation records, a compatible third-party
licence, written permission, or an independently created replacement. Record
the result here, including source URL, author, licence, modifications, and the
date retrieved or created.
